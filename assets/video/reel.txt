# REEL
# One block per video. Each block starts with the video's file name in square
# brackets, with no extension: [reel01] plays assets/video/reel01.mp4
# The thumbnail with the same number is used automatically (reel01 uses thumb01).
#
#   tags:   one or more of   Narrative, VFX, Commercial, Animation, R&D
#           separate several with commas. A filter button with no videos is hidden.
#   title:  the bold title under the player
#   note:   one line on what you did (leave it out and the line just shows the title)
#   tools:  the tools, separated by commas. They show on the right of the caption.
#   name:   short label on the thumbnail (optional, the title is used if left out)
#   thumb:  a different thumbnail file (optional)
#
# Order here is the order on the page. The FIRST block is what loads in the player,
# so put your strongest shot first. To add a video: upload reel08.mp4 and
# thumb08.png to assets/video, then add a [reel08] block. There is no limit.
# Lines starting with # are ignored. To hide a video, put # in front of its lines.
