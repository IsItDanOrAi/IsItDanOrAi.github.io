# This file builds the whole Reel section: the reels, the clips on each reel,
# and the words on the slate under the player.
#
# A REEL starts with a line like this. Its name shows on a tape label above
# the player. Reels appear in the order they are listed here.
#   == VFX ==
#
# Under a reel, one block per CLIP. The block starts with the video file name in
# square brackets, without .mp4:  [reel07] plays assets/video/reel07.mp4
# and uses thumb07 as its picture automatically.
#
#   title:  the title on the slate
#   about:  what it is and what you did. Add more about: lines for more paragraphs.
#   role:   your part in it
#   tools:  separated by commas
#   year:   when it was made
#   name:   a shorter title for the film strip (optional)
#   thumb:  a different thumbnail file (optional)
# Leave a line out, or leave it empty, and that box on the slate is hidden.
#
# The first clip of the first reel is what a visitor sees first, so lead with
# your strongest. To add a clip: upload reel08.mp4 and thumb08.png to
# assets/video, then add a [reel08] block under the reel it belongs to.
# To move a clip to another reel, move its whole block. A reel with no clips is
# hidden. Lines starting with # are ignored.
